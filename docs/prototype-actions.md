# Интерактивный прототип: элементы и действия

Режим: **демо**. Данные хранятся в браузере (localStorage, ключ `soobsha-demo-v1`) и переживают перезагрузку.
Сервера нет: нет регистрации, нет других живых людей, нет синхронизации между устройствами.
Все такие места помечены в интерфейсе.

Навигация — по «якорям» адреса (`#catalog`, `#circle-python-6` …), поэтому прототип работает и как одна HTML-страница.

## Общие элементы
| Элемент | Действие |
|---|---|
| Полоса «Демо-режим» | Объясняет ограничения; ссылка «Подробнее» → `#about-demo` |
| Логотип | → главная `#home` |
| Ссылки «Круги / Как это работает / Безопасность» | → `#catalog`, раздел на главной |
| «Войти» / «Создать аккаунт» (гость) | → `#login` (демо-вход) |
| Навигация после входа (компьютер): «Мои круги», «Найти круг», «Собрать круг», колокольчик, аватар | → `#my`, `#catalog`, `#new`, `#notifications` (со счётчиком непрочитанных), `#profile` |
| Нижняя панель (телефон): «Мои круги», «Найти», «Уведомления», «Профиль» | те же переходы, активная вкладка подсвечена |
| Подвал: «Правила», «Конфиденциальность», «О демо-режиме» | → `#rules`, `#privacy`, `#about-demo` |
| Всплывающие сообщения (тосты) | успех / ошибка / информация после каждого действия |
| Диалоги подтверждения | выход из круга, удаление, блокировка, сброс данных |

## Главная `#home`
| Элемент | Действие |
|---|---|
| «Найти свой круг» | → `#catalog` |
| «Собрать свой круг» | гость → `#login` с возвратом на `#new`; вошедший → `#new` |
| Карточки кругов | → страница круга |
| «Все круги →» | → `#catalog` |

## Демо-вход `#login`
| Элемент | Действие |
|---|---|
| Поле «Никнейм» | проверка: 3–20 символов, латиница/цифры/`_` |
| Галочка «Мне есть 16 лет» | обязательна |
| «Войти в демо» | создаёт локальный профиль (всё закрыто «Только я»), тост, переход в `#my` или туда, откуда пришли |

## Каталог `#catalog`
| Элемент | Действие |
|---|---|
| Поиск | фильтрует по названию, цели, описанию, теме, тегам — сразу при вводе |
| Темы (чипы) | фильтр по теме, «Все темы» сбрасывает |
| «Фильтры» | шторка: срок (любой / до 4 / 5–8 / 9–12 недель), «только со свободными местами», формат (любой / открытый / по заявке); «Применить», «Сбросить» |
| Быстрые фильтры «Срок», «Есть места» (компьютер) | открывают ту же шторку |
| Плашка «Подходит вашим интересам» | показывает круги с совпадающими тегами; без интересов — «Добавить интересы» → редактирование профиля |
| Пустой результат | «Ничего не нашли» + «Сбросить фильтры» + «Собрать такой круг» |
| Карточка круга | → `#circle-<id>` |
| «Собрать круг» | → `#new` |

## Страница круга `#circle-<id>`
| Элемент | Действие |
|---|---|
| «Назад» | → предыдущая страница |
| «Вступить» (открытый) | вход → становитесь участником, тост, уведомление |
| «Подать заявку» (по заявке) | шторка с сообщением (необязательно, ≤300, предупреждение о контактах) → заявка «на рассмотрении» |
| «Отозвать заявку» | подтверждение → заявка отозвана |
| «Демо: одобрить за создателя» | создатель вымышленный, поэтому одобрение — явная демо-кнопка |
| Нет мест / заблокирован | кнопка неактивна с объяснением |
| Меню «⋯» | шторка: «Пригласить» (объяснение: нужен сервер), «Уведомления этого круга» (переключатель), «Правила круга» (диалог), «Пожаловаться на участника», «Выйти из круга» |
| «Выйти из круга» | диалог с причиной (необязательно) → выход; если выходит создатель — роль переходит самому давнему участнику, если никого нет — круг закрывается |
| Вкладки «Шаги / Участники / Чат / О круге» | переключают раздел |
| Не участник | шаги, участники по именам и чат скрыты: «видят только участники» |
| **Шаги:** поле «Ваш шаг за неделю N» | ≤2000 символов, счётчик, предупреждение о контактах, «Опубликовать» |
| Реакции «Держись», «Полезно» | включаются/выключаются, счётчик меняется |
| «Комментарии (N)» | раскрывают список и поле ответа; «Отправить» |
| Меню шага/комментария | своё: «Удалить» (подтверждение); чужое: «Пожаловаться» (шторка с причинами + «также заблокировать»), «Заблокировать автора» |
| Скрытое по жалобе | заглушка «Скрыто вами» + «Показать» |
| **Участники:** строка участника | → профиль `#u-<id>`; создатель видит «Удалить из круга» (подтверждение) |
| **Заявки** (создатель) | «Принять» / «Отклонить»; «Демо: смоделировать заявку» (явно помечено) |
| **Чат:** поле сообщения | Enter/кнопка — отправить; своё сообщение можно удалить; плашка: «сообщения видите только вы» |
| **О круге** | цель, описание, срок, формат, правила |

## Создание круга `#new` (3 шага)
| Элемент | Действие |
|---|---|
| Шаг 1: название, цель, описание, тема, теги | проверка длины и обязательных полей |
| Шаг 2: срок (2–12 нед.), размер (3–8), дата старта | проверка диапазонов, дата не в прошлом и не дальше 60 дней |
| Шаг 3: формат «по заявке / открытый», проверка всех данных | «Создать круг» → тост, переход на страницу круга |
| «Назад» / «Далее» | переход между шагами, данные не теряются |
| Гость | сначала демо-вход |

## Мои круги `#my`
| Элемент | Действие |
|---|---|
| Список моих кругов | → страница круга; метка «создатель» |
| Мои заявки | «Отозвать» |
| Пустое состояние | «Найти круг» / «Собрать свой» |

## Уведомления `#notifications`
| Элемент | Действие |
|---|---|
| Уведомление | отмечается прочитанным и ведёт к кругу |
| «Прочитать все» | снимает счётчик |
| «Настройки» | → `#settings-notifications` |
| Пустое состояние | «Тихо — и это нормально» |

## Профиль
| Элемент | Действие |
|---|---|
| `#profile` — мой профиль | «Как видят другие»: переключатель «Участник моего круга / Любой пользователь» |
| «Редактировать» → `#profile-edit` | о себе (≤300), город, интересы и навыки (добавить/удалить тег, до 10), цвет аватара, видимость каждого поля; «Сохранить» с проверкой |
| `#u-<id>` — чужой профиль | показывает только разрешённые поля; меню: «Пожаловаться», «Заблокировать / Разблокировать» |
| Заблокированный | профиль скрыт, кнопка «Разблокировать» |

## Настройки
| Элемент | Действие |
|---|---|
| `#settings` | разделы: профиль, уведомления, заблокированные, данные |
| `#settings-notifications` | переключатели «в приложении / на почту» по типам, тихие часы, сводка, «выключить всё»; почта помечена «в демо письма не отправляются» |
| `#settings-privacy` | список заблокированных, «Разблокировать» |
| «Мои данные» | показывает данные JSON + «Скопировать» |
| «Сбросить демо-данные» | подтверждение → всё к исходному состоянию |
| «Выйти из демо» | подтверждение → данные удаляются |

## Что честно НЕ работает в демо
Настоящая регистрация и вход, письма, другие живые пользователи, ответы в чате, модерация жалоб,
приглашения по ссылке, синхронизация между устройствами. Всё это — на этапе разработки с сервером.
