# «Сообща» — концепция продукта (этап 3, согласована с уточнениями)

## 1. Название и позиционирование

**Сообща** — место, где люди собираются в маленькие группы, чтобы вместе довести дело до конца.

Слоган: **«Одному трудно. Вместе — получится.»**

Позиционирование: не соцсеть и не курс. Это «инструмент доведения до результата»:
маленький круг людей, одна понятная цель, срок и взаимная поддержка.

## 2. Целевая аудитория

| Сегмент | Пример цели |
|---|---|
| Самообучающиеся (18–35) | «Выучить основы Python за 6 недель» |
| Готовящиеся к экзаменам | «IELTS 7.0 к марту» |
| Меняющие профессию | «Собрать портфолио дизайнера за 2 месяца» |
| Активные жители | «Убрать берег пруда в сентябре» |
| Люди, развивающие привычку/навык | «Прочитать 4 книги по экономике за зиму» |

Старт (MVP): онлайн-круги по обучению и навыкам — их проще всего запустить без привязки к городу.

## 3. Ключевые понятия

- **Круг** — группа 3–8 человек с целью, сроком (2–12 недель) и ритмом встреч/отчётов.
- **Шаг** — еженедельный отчёт участника: что сделал, что мешает, план на неделю.
- **Поддержка** — реакция на шаг («держись», «полезно», «помогу») и комментарий.
- **Итог** — страница завершения круга: что получилось у каждого, чему научились.

## 4. Основные функции MVP

Полный список версии 1 — в разделе 16. Кратко: регистрация, публичный профиль с настройкой видимости,
каталог и поиск кругов, создание/вступление/выход, шаги и комментарии, жалобы и блокировка,
уведомления в приложении с настройками.

Чат круга, итоговая страница и достижения — версия 2.

**Не входит в MVP** (сознательно откладываем): видеозвонки, платные круги и наставники,
мобильное приложение, личные сообщения между незнакомыми людьми, офлайн-встречи и карта.

## 5. Сценарии использования

**Анна хочет выучить Python.** Ищет «python» → видит 3 круга → выбирает «Python с нуля, 6 недель,
4/6 мест» → отправляет заявку → создатель принимает → Анна видит план и пишет первый шаг.

**Игорь создаёт круг.** «Создать круг» → цель «Подготовиться к IELTS 7.0», 8 недель, до 5 человек,
по заявке → делится ссылкой с друзьями → принимает заявки → каждую неделю круг отчитывается.

**Круг завершается.** Через 8 недель появляется страница «Итог»: каждый отмечает результат,
круг получает знак «Доведено до конца», участники могут собрать новый круг с той же командой.

**Пользователь сталкивается со спамом.** Нажимает «⋯ → Пожаловаться» на сообщение →
выбирает причину → сообщение скрывается у него, жалоба уходит модератору; можно сразу заблокировать автора.

## 6. Регистрация и профили

**Регистрация** — только email и пароль (или ссылка для входа). Подтверждение «мне есть 16 лет» без даты рождения.

**Публичная часть профиля** (всё заполняется по желанию, кроме никнейма):

| Поле | Пример | Кто видит (выбирает пользователь) |
|---|---|---|
| Никнейм (уникальный, `@anna_learns`) | обязателен | всегда виден там, где вы участвуете |
| Аватар | картинка или цветная буква | Все / Участники моих кругов / Только я |
| Интересы | Python, английский, экология | Все / Участники моих кругов / Только я |
| Навыки («умею») | Excel, монтаж видео | Все / Участники моих кругов / Только я |
| О себе | до 300 символов | Все / Участники моих кругов / Только я |
| Город | по желанию | Все / Участники моих кругов / Только я |

По умолчанию всё, кроме никнейма, видят **только участники моих кругов**.

**Не собираем вообще**: телефон, адрес, дату рождения, пол, документы, ссылки на соцсети, мессенджеры.
Email нужен только для входа и никогда не показывается другим.

## 7. Общение (безопасная модель)

- **Нет открытых личных сообщений.** Написать человеку можно только внутри общего круга.
- **Нет полей для контактов** в профиле. Если в тексте шага или комментария похоже на телефон/email/ссылку
  на мессенджер — показываем мягкое предупреждение «Не публикуйте контакты: общайтесь внутри круга».
- Шаги + комментарии — основной канал, спокойный и асинхронный.
- Чат круга — во 2-й версии; видят только участники.
- Ограничения частоты действий, для новых аккаунтов — строже.

### Выход, жалобы, блокировка
- **Выйти из круга** можно в любой момент (необязательная причина). Если выходит создатель — роль переходит
  самому давнему участнику, а если участников нет — круг закрывается.
- **Пожаловаться** можно на публикацию (шаг, комментарий) и на участника. Причины: спам, оскорбления,
  мошенничество, неприемлемый контент, публикация чужих данных, другое.
  После жалобы контент сразу скрывается у того, кто пожаловался.
- **Заблокировать** пользователя: он не видит ваш профиль и публикации, не может отвечать вам
  и вступать в ваши круги; вы перестаёте видеть его. Список блокировок — в настройках, можно снять.
- **Создатель круга** может удалить участника из круга.

## 8. Сообщества и группы

Круг и есть группа. В будущем — **«Пространства»**: объединения кругов вокруг темы или организации
(например, онлайн-школа запускает 20 кругов своих студентов). Это основа для B2B-монетизации.

## 9. Поиск людей по интересам

- Поиск кругов (основной) — по теме, тегам, сроку, языку, наличию мест.
- Подбор: «Круги для вас» на основе поля «хочу научиться» — простое совпадение тегов, без скрытых алгоритмов.
- Поиск людей напрямую — только по тем, кто открыл профиль для всех.

## 10. Совместные проекты

Каждый круг — это совместный проект с целью и сроком. В MVP: общая цель, личные цели участников,
еженедельные шаги и итог. Позже — общий список задач круга (для локальных инициатив).

## 11. Уведомления (пользователь сам выбирает)

Экран «Настройки → Уведомления»: для каждого типа — переключатель «В приложении» и «На почту».

| Тип | В приложении (по умолчанию) | На почту (по умолчанию) |
|---|---|---|
| Заявка в мой круг / ответ на мою заявку | вкл | вкл |
| Ответ на мой шаг или комментарий | вкл | выкл |
| Новый шаг в моём круге | выкл | выкл |
| Напоминание о дне шага | вкл | выкл |
| Круг завершается / итог | вкл | выкл |
| Новости «Сообща» | выкл | выкл |

Плюс: «тихие часы», «сводка раз в день вместо отдельных писем», «выключить всё».
Никогда: «вы давно не заходили», счётчики-приманки, тёмные паттерны отписки.

## 12. Система достижений (за результат, не за время)

| Знак | За что |
|---|---|
| Первый шаг | Опубликован первый отчёт |
| Доведено до конца | Завершён круг (отмечен итог) |
| Опора | 10 полезных комментариев, отмеченных другими |
| Собиратель | Создан круг, который дошёл до конца |
| Наставник на шаг | Помог новичку (отметка от участника) |

Нет: «серий» дней подряд, рейтингов «кто больше», очков за вход.

## 13. Безопасность и модерация

- **Жалобы** на пользователя, круг, шаг, комментарий, сообщение — с причиной.
- **Блокировка**: заблокированный не видит ваш профиль и шаги, не может писать вам и вступать в ваши круги.
- **Модерация**: роль модератора, очередь жалоб, скрытие контента, бан. Создатель круга может удалить участника.
- **Антиспам**: ограничение частоты, лимиты для новых аккаунтов, запрет ссылок в первые часы, проверка вводимых данных.
- **Данные**: RLS в базе (каждый видит только то, что ему разрешено), HTTPS, пароли хранит Supabase Auth.
- **Права пользователя**: выгрузить свои данные, удалить аккаунт.
- Правила сообщества — короткие и понятные, показываются при создании круга.

## 14. Как сделать интересным без манипуляций

- Естественный повод вернуться — свой круг и его ритм, а не уведомления-крючки.
- У каждого круга есть конец — приложение не стремится удерживать бесконечно.
- Прогресс виден наглядно: недели, шаги, итог.
- Тёплые формулировки и поддержка вместо соревнования.

## 15. Монетизация (позже, не в MVP)

1. «Пространства» для онлайн-школ, вузов, компаний — платная подписка.
2. Круги с наставником — комиссия платформы.
3. Расширенные функции для создателей кругов (шаблоны, аналитика своего круга).

Базовое использование для людей — бесплатно.

## 16. Этапы разработки

**Версия 1 — основной функционал (MVP).** Сначала делаем качественно и проверяем.
1. Регистрация, вход, выход, восстановление пароля.
2. Профиль: никнейм, аватар, интересы, навыки, о себе, город + видимость каждого поля.
3. Каталог кругов и поиск (тема, теги, срок, свободные места).
4. Создание круга, заявка/вступление, **выход из круга**, удаление участника создателем.
5. Страница круга: участники, недели, шаги, комментарии.
6. **Жалобы** на публикацию и участника, **блокировка**, простая очередь модерации.
7. Уведомления в приложении + **настройки уведомлений**.
8. Защита: RLS, ограничение частоты, проверка ввода, предупреждение о контактах.
9. Адаптивность (телефон / планшет / компьютер) и тесты Playwright на всё перечисленное.

**Версия 2 — после проверки первой версии.**
Чат круга, итоговая страница и достижения, письма на почту, вход через Google, загрузка фото в шаги,
расширенная модерация.

**Версия 3 — развитие.**
«Пространства» для школ и компаний, круги с наставником, локальные инициативы со списком задач, монетизация.
