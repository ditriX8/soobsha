# Сообща

Веб-приложение для маленьких групп («кругов») с общей целью и сроком.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Проверки

```bash
npm run lint        # стиль кода
npm run typecheck   # типы TypeScript
npm run build       # сборка
npm run test:e2e    # тесты Playwright (компьютер + телефон)
```

Правила работы над проектом — в [CLAUDE.md](CLAUDE.md).
