# EMBER Milano — fire-grilled burgers

Одностраничный сайт бургерной в Милане (английский язык, цены в евро): тёмный «стеклянный» интерфейс с оранжевым акцентом и объёмными фото, которые поворачиваются за курсором/пальцем.

**Стек:** React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · Lucide Icons · Vite

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
npm run preview  # просмотр сборки
```

## Что работает

- Поиск в hero и в меню, фильтр по категориям, «Избранное» (сохраняется в localStorage), «Показать ещё»
- Карточка товара: размер, добавки-переключатели, количество, пересчёт цены
- Корзина: количество, удаление, допродажа, прогресс бесплатной доставки, промокоды `FEELGOOD` (−15%) и `CIAO10` (−10%), бесплатная доставка от €30
- Оформление: доставка/самовывоз, телефон в международном формате, валидация, время, способ оплаты, экран подтверждения
- Комбо дня с таймером до полуночи, копирование промокода
- Отзывы: карусель + форма нового отзыва; FAQ-аккордеон; ссылки на маршрут в Google Maps
- Подписка на рассылку и SMS-ссылка на приложение с валидацией
- Мобильное меню, нижняя панель в стиле приложения, индикатор прокрутки, уважение `prefers-reduced-motion`

> Бэкенда нет: заказ сохраняется в `localStorage` (`ember-milano:orders`), подписка/SMS/отзывы показывают уведомление.
> Для реальных заказов подключите API в `src/components/CartDrawer.tsx` (функция `submit` в `CheckoutStep`).

## Структура

```
src/
  data.ts            меню, опции, отзывы, FAQ, контакты
  store.tsx          корзина, избранное, фильтры, уведомления
  components/        секции и UI-компоненты
```

## Объёмные фото (2.5D)

`src/components/DepthPhoto.tsx` — WebGL-шейдер: настоящее фото смещается по карте глубины
(`public/img/*-depth.png`, посчитаны нейросетью Depth Anything V2 Small, Apache-2.0),
плюс перспективный поворот и блик. Без WebGL показывается обычное фото.
